# CODING RULES

- Preserve existing behavior unless an approved task explicitly changes it.
- Do not silently remove features, tests, compatibility behavior, or stored data.
- Keep changes bounded to the approved work package.
- Add or update tests for changed behavior.
- Record exact test commands and exact results.
- Do not claim success when verification is incomplete.
- Do not overwrite unrelated uncommitted work.
- Keep secrets, caches, environments, generated packages, and private references out of Git.
- Use verified checkpoints before large transitions.
