# CHATGPT WEB READING ORDER

When reviewing the repository, read in this order:

1. `.ai/HANDOFF/TO_CHATGPT.md`
2. `.ai/CURRENT_STATUS.md`
3. `.ai/NEXT_TASK.md`
4. `.ai/SESSION.json`
5. `.ai/METRICS.json`
6. Latest file in `.ai/CHECKPOINTS/`
7. Relevant files in `.ai/DECISIONS/`
8. Relevant files in `.ai/KNOWLEDGE/`

Treat source code, Git history, and test evidence as the final authority when state files conflict.

Clearly distinguish:

- Verified facts
- In-progress work
- Planned work
- Assumptions
- Missing information
