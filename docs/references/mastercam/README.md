# Mastercam

Nhánh này dành cho ghi chú và chỉ mục tham khảo Mastercam, bao gồm thuật ngữ,
quy trình lập trình và các quy ước xuất chương trình NC có thể giúp đối chiếu
với HMS CAD/CAM.

| Thư mục | Nội dung dự kiến |
| --- | --- |
| `manuals/` | Chỉ mục manual và ghi chú theo phiên bản Mastercam. |
| `workflows/` | Quy trình tạo job, setup, toolpath và kiểm tra. |
| `post-processors/` | Ghi chú post/controller và định dạng NC. |
| `examples/` | Ví dụ tối giản, đã loại bỏ dữ liệu khách hàng. |
| `notes/` | So sánh thuật ngữ và quyết định thiết kế nội bộ. |
| `assets/` | Ảnh chụp hoặc sơ đồ chỉ dùng cục bộ. |
| `external/` | File tải về hoặc file nhị phân chỉ lưu cục bộ. |

Khi thêm tài liệu, ghi metadata nguồn theo [`../SOURCE_TEMPLATE.md`](../SOURCE_TEMPLATE.md)
và tôn trọng điều kiện phân phối của nhà cung cấp.
